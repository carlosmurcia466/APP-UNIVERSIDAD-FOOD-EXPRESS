# Food Express — Android Application

Food ordering Android application developed as an academic project.

## Overview

The application provides a mobile interface for browsing food products and managing an ordering workflow.

## Features

* Product browsing
* Food ordering workflow
* User interaction through Android UI
* Backend/web service integration
* Structured application navigation

## Technologies

* Java
* Android
* Android Studio
* Gradle
* REST/Web Services

## Project Structure

The Android application contains the mobile interface and supporting service integration required for the application workflow.

## Purpose

This project demonstrates experience developing Android applications and integrating mobile interfaces with backend services.
